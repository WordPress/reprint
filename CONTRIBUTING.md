# Contributing to Reprint

Start with the [contributor guide](https://developer.wordpress.org/reprint/contributing/). It links
to development setup, tests, architecture, protocol reference, and releases.

For a code change, read the [repository working rules](https://github.com/WordPress/reprint/blob/trunk/AGENTS.md), then follow
[Set up Reprint development](https://developer.wordpress.org/reprint/contributing/development/).

For copying a site or running the client from your product, use the
[Reprint handbook](https://developer.wordpress.org/reprint/).
