# Contributing to Reprint

Start with the [contributor guide](docs/contributing/contributing.md). It links
to development setup, tests, architecture, protocol reference, and releases.

For a code change, read the [repository working rules](AGENTS.md), then follow
[Set up Reprint development](docs/contributing/development.md).

For copying a site or running the client from your product, use the
[Reprint handbook](docs/handbook/README.md).
