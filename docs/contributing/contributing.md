# Contribute to Reprint

- [Report a problem](https://github.com/WordPress/reprint/issues). Include the client and plugin versions, the command with credentials removed, and the expected result.
- [Change code or tests](https://developer.wordpress.org/reprint/contributing/development/)
- [Change documentation](https://developer.wordpress.org/reprint/contributing/development/#change-documentation)
- [Understand the transfer code](https://developer.wordpress.org/reprint/contributing/architecture/)
- [Publish a release](https://developer.wordpress.org/reprint/contributing/releases/#publish-a-stable-version)
- [Update screenshots](https://developer.wordpress.org/reprint/contributing/releases/#update-screenshots-without-releasing-code)

## Transfer protocols

- [Pull HTTP](https://developer.wordpress.org/reprint/contributing/pull-http/)
- [File push](https://developer.wordpress.org/reprint/contributing/push/)
- [Database push](https://developer.wordpress.org/reprint/contributing/database-push/)

File and database push require a separately configured source build. The WordPress.org plugin provides downloads only.

[Why Reprint uses HTTP and streaming](https://developer.wordpress.org/reprint/understand-reprint/how-it-works/)
