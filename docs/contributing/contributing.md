# Contribute to Reprint

- [Report a problem](https://github.com/WordPress/reprint/issues). Include the client and plugin versions, the command with credentials removed, and the expected result.
- [Change code or tests](development.md)
- [Change documentation](development.md#change-documentation)
- [Understand the transfer code](architecture.md)
- [Publish a release](releases.md#publish-a-stable-version)
- [Update screenshots](releases.md#update-screenshots-without-releasing-code)

## Transfer protocols

- [Pull HTTP](pull-http.md)
- [File push](push.md)
- [Database push](database-push.md)

File and database push require a separately configured source build. The
WordPress.org plugin provides downloads only.
