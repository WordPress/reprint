# Get started

Try the demo or make your first copy of a site you administer.

- [Try Reprint](https://developer.wordpress.org/reprint/getting-started/try-reprint/) with the public demo.
- [Clone your site](https://developer.wordpress.org/reprint/getting-started/copy-a-site/) to the computer you choose.
- [Authorize the Reprint client](https://developer.wordpress.org/reprint/getting-started/authorize-client/) if you manage the source site's access.
- [Check requirements and downloads](https://developer.wordpress.org/reprint/getting-started/requirements/) for PHP, database, and disk-space requirements.
